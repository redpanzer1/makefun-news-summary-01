# news-summary-01 entry

A summary of the world's news of Wednesday 11 November 2026, written for the
make.fun `news-summary-01` bounty. `summary.txt` holds the summary (English,
1,896 characters); `main.ts` copies it to the grader's output file.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt`, byte-identical to `summary.txt`. Node 22,
standard library only, no network.
